## 👋 About Us

Welcome to **IntegraTech** — the official GitHub organization for our team of 4th-year Computer Science students at the **University of Caloocan City**. We're dedicated to designing, developing, and delivering modern software solutions that solve real-world problems.

Our flagship project, **BLOCA**, is an IoT-monitored plastic-to-brick compactor with machine learning-based grading — transforming plastic waste into construction-ready bricks while tracking the entire compaction and grading process end-to-end.

---

## 🏗️ Featured Project: BLOCA

**BLOCA** is an integrated ecosystem that combines IoT hardware, machine learning, and modern web/mobile applications to address plastic waste management and sustainable construction.

## 🛠️ Technology Stack

Our projects leverage modern, industry-standard technologies across the full stack:

### Frontend
- **Web**: React 19, Next.js 16, TypeScript, Vite
- **UI/Styling**: Tailwind CSS v4, Shadcn UI, Radix UI, Base UI
- **State Management**: TanStack Query, Zustand
- **Routing**: TanStack Router, Next.js App Router, Expo Router

### Backend
- **Framework**: Django 6, FastAPI
- **API Design**: Django Ninja, REST, WebSocket (Django Channels)
- **Authentication**: Django Allauth (Headless)
- **Real-Time**: MQTT, Server-Sent Events, WebSocket

### Mobile
- **Framework**: React Native, Expo SDK 57
- **UI**: Custom UI library (HeroUI Native), Tailwind Variants
- **Navigation**: Expo Router
- **Animations**: React Native Reanimated, Shopify Skia

### Machine Learning
- **Training**: TensorFlow, scikit-learn, pandas
- **Serving**: FastAPI
- **Deployment**: Docker, model serving endpoints

### Database & Infrastructure
- **Database**: PostgreSQL (with psycopg3)
- **Cache/Queue**: Redis (with Channels Redis)
- **Containerization**: Docker, Docker Compose
- **Web Server**: Gunicorn, Uvicorn, Nginx
- **IoT Protocol**: MQTT (Paho MQTT)

### DevOps & Quality
- **Package Management**: Bun, UV (Python), npm/pnpm
- **Code Quality**: ESLint, Ruff, MyPy, Prettier
- **Type Checking**: TypeScript 6, Python type hints with MyPy
- **Git Hooks**: Husky, lint-staged, pre-commit
- **Commit Standards**: Commitlint (Conventional Commits)

### Design & Prototyping
- **UI/UX Design**: Figma
- **3D Modeling**: Blender
